# 效率与质量实验设计

**没有实测结果。** 本文件预先定义实验，不承诺倍率。

## 1. 假设与因果归属

H1：批处理减少模型往返。H2：产物引用减少中间数据进入上下文。H3：有限并行降低可并行任务的等待。H4：持久化与局部失效减少故障后重做。H5：上述收益扣除维护成本后仍值得保留。

| 组 | 内容 | 归属 |
|---|---|---|
| A | 现有 Agent＋同一套工具的逐步调用 | 当前方式基线 |
| B | A 的相同适配器＋成熟批处理/代码组合，允许合理缓存与重试 | 工具与编排优化基线，不能故意削弱 |
| C | B＋Runtime 的契约、产物引用、状态、策略、恢复 | 运行时增量 |
| D（可选） | 上游 UFO/Cua/Rivet 完整系统在可比任务上执行 | 端到端产品对照；无法统一条件时不得作因果归因 |

A 与 B 的差异不能算作 C 的创新。B 已有的安全确认、批量能力和恢复能力必须正常启用并记录；不能主动关掉以制造差距。

## 2. 任务与数据

T1：100 份合成 CSV 的分币种汇总与异常核验；规模 10/100/1000 文件作为扩展条件，固定随机种子但保留不同变体。T2：本地 mock 草稿站多字段填写、回执查询与导出。T3：合成文件清单与去重/改名副本，可作为独立任务族。

规则中应包含少数需要判断的歧义输入，正确行为可以是请求澄清，而不是擅自决定。主要规模比较仍固定规则，不让模型能力差异掩盖执行开销。

每个变体都有预先生成的独立标准答案与验收器版本。基准输入均为合成数据，不使用任何真实交易、账号、客户或公司资料。

## 3. 故障注入

F1 worker 中途退出；F2 输出创建后、journal 提交前退出；F3 mock 服务收到写入但响应丢失；F4 输入版本变化；F5 写锁被占用；F6 页面结构变化/字段缺失；F7 授权撤回；F8 产物丢失/损坏；F9 空间不足/输出超限；F10 非授权路径或网络访问；F11 超时取消；F12 旧 worker 回传迟到结果。

正常与故障任务分开报告。没有真实模拟的故障标记未测，不用一句“支持恢复”代替。

## 4. 记录口径

| 指标 | 定义 |
|---|---|
| 合格交付率 | 通过独立验收的尝试数 / 所有计划内尝试数 |
| 端到端时间 | 用户提交到合格交付或终止，包括排队、审批等待、重试 |
| 机器活跃时间 | 扣除用户等待后的执行/推理时间，单独报告 |
| 人工占用 | 用户实际操作、确认、排错时间，不把后台等待算成人工 |
| 模型往返 | 所有实际模型请求，包括重规划、验证模型和重试 |
| Token | 输入、输出、缓存命中分列；未获得计量时标记 missing，不能填 0 |
| 重复工作量 | 同一语义意图被再次执行的节点/数据项及耗时 |
| 数据搬运 | 发送给模型的文本字节与产物内部流转字节分列 |
| 成本 | 模型＋环境＋失败重试；模型单价和货币记录核验日期 |
| 资源 | 峰值内存、CPU、进程/浏览器数、环境启动时间 |
| 维护 | 基线配置与运行时实现/适配/修复耗时分别记录 |

失败和超时不能从图表分母中删除；成功耗时要与合格率一起展示。不得把超时标为“0 秒完成”。

## 5. 控制与统计

固定模型/版本/采样设置、工具版本、提示策略、权限、硬件、并发额度、输入变体、验收器和网络条件。若只能通过托管 Agent 访问而无法固定内部模型，记录限制，把结果作为产品级比较而非运行时因果结论。

先用少量配对实验估算方差和可行性，再按最小有意义差异选样本量。每个任务族至少 10 个不同变体，探索阶段每变体/配置至少 3 次，随机交错 A/B/C 执行顺序。30 次不足以证明高可靠性，尤其不能凭零失败宣称 99% 成功。

冷启动/热会话、缓存开/关、正常/故障、不同并行度分层报告。报告原始配对差异、中位数、区间估计；p95 仅在样本足够时报告，否则标不稳定。模型推理随机性和服务端排队属于结果不确定性。

## 6. 预注册投资门槛（目标，不是事实）

进入平台化投入前，C 对强基线 B 至少在两个任务族上显示人工占用或失败恢复时间降低 30%，且质量无有意义下降；干净无故障任务的中位耗时回退不超过 10%。所有受控安全负例必须按预期拒绝，且不得出现原始输入修改。

正式试验前冻结成功率非劣界限、超时阈值、最小样本量和费用上限。初步建议非劣界限 2 个百分点，但若样本不足以支持，则结论是证据不足，而非默认合格。阈值变更必须在新实验之前记录原因。

## 7. 停止规则

如果 B 已达到目标，或 C 只能通过降低核验/放松权限获得速度，停止平台化。若性能提升只来自特定适配器，保留该适配器，不把收益误归为 OS。负结果与未运行项同样进入公开报告。
