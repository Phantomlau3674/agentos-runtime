# 适配器与支持矩阵

状态：所有适配器待实现或待评估；下表不是已经支持的软件清单。

| 适配器 | 阶段 | 允许能力 | 关键限制 |
|---|---|---|---|
| mock | M1 | 固定输入输出、故障注入、虚拟时钟 | 不代表真实应用 |
| files | M1 | 授权输入快照、生成副本、哈希清单 | 不覆盖原稿、不任意遍历、不跟随危险链接 |
| tabular | M1 | CSV 校验/聚合、JSON/CSV 输出 | 无宏、公式计算或 Excel 保真承诺 |
| browser | M3 | 专用会话、本地 mock 草稿、语义定位、读回核对 | 不导入个人 profile、不随意访问网站 |
| desktop | M5 条件项 | 经批准的 Cua/UFO 桥接与只读检查 | 实际平台、会话、应用版本逐一验证 |
| blender | M5 条件项 | 合成场景副本、显式对象批量参数修改 | 不接任意 Python 执行；只支持注册操作 |
| office | M5 条件项 | 固定模板、明确对象/字段、新输出 | 不承诺任意文档保真或无桌面自动化 |

## 所有适配器必须提供

能力清单、参数/结果 schema、受信效果声明、对象版本策略、资源键、超时取消语义、错误分类、幂等支持/查询方式、后置条件、数据分级、兼容版本和测试入口。

不把底层返回 success 当成任务成功。浏览器点击保存后必须读回草稿内容；文件写入后必须检查实际文件哈希/格式；原生应用改动需验证对象与产物。

## Browser 选型实验

Playwright 和 agent-browser 在同一本地测试站上比较：首次启动/复用会话耗时、连续动作调用数、结构化结果、批次中断、页面状态变化、取消、进程退出、截屏/产物大小与网络限制。选择一个作为默认，只保留另一套基线脚本。[调研 S07、S13](research/SOURCES.md)

禁止将任意 eval/js/shell 作为“通用 escape hatch”。需要缺失能力时，新增受审查动作或明确不支持。第三方 MCP 服务器不是自动受信适配器；工具注解不能直接决定权限。

## 原生软件接入的独立前置条件

采集实际操作系统、应用版本、语言、显示缩放、桌面会话和授权条件；使用隔离测试用户或虚拟机。Windows 交互 worker 与后台调度分开设计；不能未经验证就让服务直接操纵用户桌面。此处是工程约束检查项，不是对当前机器配置的断言。

Office/Blender 等实际 API、许可证和自动化限制在 EXP 任务中重新查官方文档。未核验前不把通用 GUI fallback 当成“兼容所有版本”。
