# 科学设计：让不确定推理产生有边界的行动

状态：研究与设计建议，未实现、未做系统性能实验。与 [系统提案](01_SYSTEMS_OPTIMIZATION.md) 配合阅读。

## 1. 把未知、推测和过期做成状态

运行时能确认自己的日志，不一定能确认外部世界。请求超时可能是未送达，也可能是效果已产生但响应丢失。因此执行进度与效果证据应分别记录。

例如：未发出/能确认无效果；已发出/效果未知；已收到响应/尚未核验；产物核验过/仅对指定版本成立；历史结果存在/来源已过期。unknown_effect 不是普通失败，不能自动重发。

每条重要观察记录来源、观察时间、对象版本、证据引用、有效条件及失效规则。未知不填成 false，推测不升级为事实。首版用显式状态即可，不需要先做概率世界模型。可借鉴部分可观察规划，但不把机器人研究成绩当桌面 Agent 的实测。

## 2. 目标合同与验收器

先表达“改什么、保持什么、允许什么、怎样检查、哪些仍需人判断”，再选择动作。目标合同来自用户意图的确认或明确假设；不能为了便于测试，把困难目标换成容易测量的代理指标。

例如几何对象坐标不变，不必然意味着画面中的遮挡和视觉关系不变。合同必须把可程序化约束和审美判断分开。

交付物包含输入版本、产物版本、验收器版本、已检查/未检查条件、证据位置。哈希只证明字节关系，测试只覆盖已执行情况，模型自评不是独立验证。普通回执不叫形式化证明；只有在定义的形式系统和假设内完成证明才作对应声明。

验收器不应让受测模型自行改标准答案以宣称通过。定义 false_success：系统宣布完成，但未满足目标合同。将其与正确停止和普通失败分开统计。

## 3. 面向下一次决策的上下文

把上下文拆为结构化的当前目标/约束/权限/版本/未决问题，及可检索的原文、旧方案、讨论和轨迹。普通摘要不能静默删改约束。用户修改要求时建立新版本，明确替代关系并使相关旧计划失效。

工作上下文应回答：目标是什么、哪些条件必须保持、哪些结果有证据、哪些仍未知、下一个判断是什么、依据在哪里。关键可执行限制还要进入运行时，不只依靠模型记忆。

比较压缩方案时测同一批关键决策是否保留，特别是禁止条件、否定条件、过期版本和推测来源；不能只测 token 压缩比例。信息瓶颈是设计启发，不是可直接保证最优 Agent 记忆的公式。

## 4. 小核心、领域语义不抹平

统一资源引用、动作契约、权限、任务状态和结果证据，保留适配器领域语义。文件删除、记录删除、场景对象删除不能只因都叫 delete 就视为相同操作。

全电脑对象图不作为首要交付。先用小而严格的交接协议连接 Agent 和具体领域工具，避免为统一抽象而丢掉依赖、恢复和副作用信息。

底层检查不能替代业务端判断。可信计算基越小，权限和完成状态越容易审阅。沙漏式架构与端到端原则是设计参考，不是接口越少越好的无条件定理。

## 5. 经验固化为受限能力

候选流程→隔离执行→独立验收与反例→修正或缩小范围→带版本启用。参考 CEGIS 的候选与反例循环，而不是只有模型自我反思。

新能力同时保存输入结构、顺序语义、依赖版本、适用条件、失败退出和回退路径。跨文件重复 ID 反例应成为后续并行化、缓存和改写的永久回归要求。

有限测试未发现反例不等于全输入正确。发现新能力不自动授予权限；不能让模型从一次成功轨迹升级到任意代码或外部发送。首版可先由人批准候选，不必实现自主自我修改。

## 6. 同时追求安全和推进

永远拒绝执行会有很低的事故率，但没有生产力。评估必须同时覆盖安全性与推进能力：有授权且满足条件的任务，应在预算内交付或给出可解释阻塞，而非无限等待、重复确认或循环自查。

分别统计正确完成、正确停止、假成功；同时报告覆盖范围和人工介入。不能靠只接简单任务提升表面成功率。

统计提醒：即便166次独立同分布随机试验全部成功，二项模型下失败概率的95%单侧上界仍为 `1-0.05^(1/166)≈1.79%`。手写166个不同测试不是这种抽样，不能用这个公式宣传真实失败率；它只是说明有限成功样本的证据限制。

## 7. 可证伪研究计划

| 假设 | 对照 | 否定条件 |
|---|---|---|
| 显式未知/过期状态减少错误操作 | 同工具下有/无证据层；注入变更与响应丢失 | 错误未减少，只增加延迟和人工工作 |
| 独立验收减少假成功 | 工具返回、模型自评、领域验收对照 | 漏掉主要错误，或检查成本超过避免的返工 |
| 受限复用流程降低重复任务成本 | 重新规划与固化流程在未见变体上对照 | 只适合旧样例、频繁误用或维护成本过高 |

对会改变环境的策略，分别从同一初始快照执行。不能让不同动作的策略共享同一条固定后续观察日志，因为动作改变了本应观察到的世界。固定轨迹适用于部分只读评估，不是通用交互反事实环境。

性能实验需事先冻结任务、样本、失败定义、停止条件和预算；保存失败与人工接管。历史小实验只用于选择下一项研究，不当作最终结论。

## 三项优先产物

目标合同与验收器回答是否做对；状态证据回答知道与不知道什么；反例及对照环境回答哪些设计值得保留。先建立这三项，再围绕证明了的需求扩大能力。
