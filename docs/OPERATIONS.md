# 运维与非技术使用者体验

这是待实现要求，不是可执行产品手册。

## 启动

预览应提供固定版本安装与一个不需要账号/API Key 的合成示例。启动检查操作系统、依赖、数据库/产物目录、空间与浏览器可用性；不满足时解释原因，不要求关闭安全功能。

默认只在本地监听或使用 stdio；没有明确需求不开放网络控制端口。需要 web 控制面时必须验证绑定地址、来源、认证和 CSRF 防护，不能依赖“只有 localhost”这一假设。

## 运行

任务预览应列出输入、输出目录、可能效果、资源上限、待确认点和明确不支持项。运行视图显示阶段、异常和已保留成果，Agent 不抢用户主桌面作为默认体验。

自动重试数量有上限，等待人工与机器执行时间分开显示。费用计量不可得时不伪报精确金额；付费模型默认不用，配置后才能启动相应实验。

## 失败

用户错误信息模板：哪里失败；哪些结果已保留；原始输入是否保持不变；是否可能已有外部效果；可以继续、重新规划还是需要人工对账。没有证据时说不知道，不把模糊状态写成成功。

诊断包含版本、任务/节点 ID、状态转换、脱敏错误、产物完整性检查；不默认包含全文输入、完整 prompt、Cookie、请求头或浏览器 profile。公开 Issue 前由用户查看导出范围。

## 数据生命周期

数据库升级前备份并验证迁移；失败不破坏唯一副本。清理先 dry-run，保护活跃任务、已采纳产物和必要审计证据。可释放未引用 staging；已丢失的输入无法由记忆凭空恢复。

## 发布

先离线测试，再本地集成，再平台特定测试。CI 中未执行的平台测试必须标记 skipped/unverified。预览包附实际兼容矩阵、依赖许可、已知问题和性能证据，不放空的 passing 徽章。

Windows/Blender/Office 等后期扩展每项有独立安装与失败恢复说明；不能从单个 mock 演示推断通用兼容性。
