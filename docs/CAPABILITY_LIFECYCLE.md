# 能力启用生命周期（REV-018）

候选能力进入 Runtime 的固定流程；有限测试不冒充证明，候选代码只在授权环境中执行。

## 流程

1. **候选**：明确输入/输出契约、效果类别、资源键、失败退出映射；写候选任务条目。
2. **反例**：先造一个能证伪它的例子（如 REV-002 的跨文件重复 ID 反例）；反例未通过前不实现。
3. **测试**：等价语料、边界（溢出/编码/顺序）、取消与恢复、资源耗尽；差分对照参考实现。
4. **批准**：所有者批准绑定主体、计划哈希、效果与版本、有效期；范围变化即失效（ADR 0003 原则）。
5. **版本化启用**：进 engine_fingerprint / 注册表 / ADR；旧回执按既有规则失效。
6. **回退条件**：净收益不足、等价性破裂、恢复语义受损 → 不引入或退回适配器方案（如 REV-019 的否定决策）。

## 边界

- 测试外输入必须退出（unknown effect → 显式停止，不靠 fallback 重复执行）。
- 能力学习不授予新权限：新动作要进注册表并经 owner policy，模型不能自批。
- 本流程已应用于：整数分内核（REV-005 采纳）与原生实现（REV-019 否定）。
