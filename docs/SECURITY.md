# 安全设计与明确边界

状态：威胁模型和测试要求，未通过实现安全审计。禁止称为生产级沙盒。

## 受保护资产

原始输入、产物、浏览器会话、模型或服务凭据、控制面授权、执行记录、电脑资源与用户时间。首版只处理合成输入；即使如此也不能省略权限与路径测试。

## 信任分区

不信任模型生成的计划、网页内容、导入文件、工具返回文本和社区插件。信任范围限于经审查固定版本的 Runtime 和注册适配器；这个假设必须公开。

安全边界是策略代理与执行环境，不是提示词。主机已被攻陷、同用户恶意进程、Agent 另有不受约束的 Shell 时，本 Runtime 不具备整机隔离保证。

## 默认规则

无任意宿主代码执行；不自动安装插件；不继承浏览器个人登录态；不扫描整个硬盘；不自动上传遥测或日志；不授予管理员权限；不执行发送/购买/删除原稿。准许范围是明确的项目快照、输出目录和本地模拟网页 origin。

## 威胁与防护测试

| 威胁 | 要求 | 必测反例 |
|---|---|---|
| Prompt injection | 文件/网页文字不改变权限或执行策略 | CSV 单元格要求读取其他目录、页面要求上传凭据 |
| 路径逃逸 | 规范化+句柄级约束、拒绝不支持的链接/重解析路径 | ../、符号链接、Windows junction/UNC/ADS、大小写与编码变体 |
| 检查与使用之间变化 | 快照输入，或者安全打开时核对对象 | 通过检查后替换链接或移动文件 |
| 权限扩大 | 最终解析对象上再授权 | 批量参数中的一项指向授权外对象 |
| 页面越域/SSRF | URL/origin 白名单与网络边界 | 跳转、iframe、子资源、WebSocket 指向非授权源 |
| 凭据泄漏 | 凭据 broker 使用，日志和模型结果不包含明文 | 异常堆栈、请求头、重定向 URL 或截图暴露秘密 |
| Agent 自我批准 | 无 Agent 可用审批能力 | 工具参数伪造 approved=true；重用过期审批 |
| 重放副作用 | 幂等声明与结果对账 | 已写草稿但响应丢失后再次调用 |
| 资源耗尽 | 行数、字节数、进程数、时间和并发有界 | 超大文件、递归目录、循环 DAG、无限页面等待 |
| 产物外泄 | 句柄访问检查、摘要最小化、日志脱敏 | 猜到另一个任务的 artifact_id 后请求读取 |
| 供应链 | 版本锁定、来源许可、依赖审核 | 未审核插件尝试自动启用或运行安装脚本 |

路径 string startswith 不构成目录隔离。不同 OS 的句柄约束能力不同，无法安全实现的路径形式先拒绝；测试清单是要求，不是声称所有攻击已阻断。

浏览器 context 隔离 Cookie 不等于阻止网络访问或沙盒逃逸。若测试网页可发起网络请求，需用环境层限制和浏览器拦截联合约束；仅检查顶层导航不够。首版可在无外网的测试环境运行。

## 授权

人类审批必须绑定主体、准确目标、已解析参数与数据摘要、plan_hash、操作效果、输入/目标版本和有效期；批准一次计划不等于批准今后所有变化。取消/撤销后，未执行节点不能借旧许可继续启动。

本地 CLI 审批是开发便利，不是针对同宿主恶意进程的强认证。公开预览前，人类控制面与 Agent worker 需要有清晰的身份和能力分离；做不到时限制为无人类审批的只读/副本合成任务。

## 凭据与日志

v0 不需要个人服务凭据。以后凭据保存在 OS keyring 或选定 secret store，由 broker 注入必要请求，避免进入模型上下文。不能声称“模型看不到 token”便可阻止凭据被滥用：有调用权限仍可能产生副作用，因此目标与动作都需限制。

保留结构化元数据和必要证据，不默认保存全部输入、完整聊天或截图。导出诊断包时预览并脱敏。公开仓库不放运行数据。

## 放行门槛

通过有限安全用例仅能说明该版本在该测试范围的表现。出现越界写、秘密泄露、真实效果盲重试或 Agent 自我审批即停止预览发布；不得为了演示临时关闭防护。
